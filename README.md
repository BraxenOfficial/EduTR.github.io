# EduTR — Öğrenci Akademik Takip Platformu 🎓

Türk lise ve ortaokul öğrencileri için MEB müfredatına ve en güncel not yönetmeliğine (Türkçe/Edebiyat ve Yabancı Dil için dinleme/konuşma sınavları dahil) uygun olarak tasarlanmış, modern ve animasyonlu bir not ve ortalama hesaplama platformudur.

## 🚀 Özellikler

- **MEB Uyumlu Detaylı Hesaplama**:
  - Türkçe ve İngilizce dersleri için **Konuşma (Speaking) %25** ve **Dinleme (Listening) %25** sınav ağırlıklarını içeren gelişmiş hesaplama.
  - Her ders için **2 Sözlü (Ders İçi Etkinlik)** notu girişi.
  - **Proje Notu** seçeneği (checkbox ile aktif/pasif edilebilir).
- **Dil Desteği (TR / EN)**: Türkçe ve İngilizce dilleri arasında tek tıkla geçiş.
- **Dönem & Genel Ortalama**: Kredi/katsayı ağırlıklı dönem ortalaması hesaplama ve grafiksel analiz.
- **MEB Duyuruları**: Güncel sınav takvimi, burs ve duyuruların listelenmesi ve aranması.
- **Modern Arayüz**: Glassmorphism tasarımı, arka plan partikül animasyonları, pürüzsüz geçişler ve mobil uyumluluk.

## 🛠️ Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için:

1. Bu depoyu klonlayın:
   ```bash
   git clone https://github.com/KULLANICI_ADINIZ/edutr.git
   ```
2. Proje klasörüne gidin:
   ```bash
   cd edutr
   ```
3. `index.html` dosyasını tarayıcınızda çift tıklayarak doğrudan açın veya yerel bir sunucuda çalıştırın:
   ```bash
   python -m http.server 3000
   ```
4. Tarayıcınızda `http://localhost:3000` adresine gidin.

## 📦 GitHub Pages'e Yükleme

Bu projeyi ücretsiz olarak internette yayınlamak için:
1. GitHub'da yeni bir repository (depo) oluşturun.
2. Klasör içindeki dosyaları commit edip push edin.
3. Repository ayarlarına (Settings) gidin, **Pages** sekmesinden kaynağı `main` branch olarak seçip kaydedin.
4. Birkaç dakika içinde siteniz `https://kullanici-adiniz.github.io/edutr/` adresinde yayında olacaktır.
